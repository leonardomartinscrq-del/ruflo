## PASSO 0 — Gerar o PDF do ebook (1 min)

1. Abra `ventures/_lancamento/funcionarios-digitais.html` no Chrome (arrastar para uma aba)
2. `Ctrl+P` → Destino: **Salvar como PDF** → Margens: Padrão → ✅ Gráficos de plano de fundo

## PARTE 1 — HOTMART (≈20 min) · app.hotmart.com

### 1.1 Criar produto
- **Menu:** Produtos → Cadastrar produto → **E-book**
- **Nome:** `Funcionários Digitais — O Guia Prático de Agentes de IA para Pequenos Negócios`
- **Categoria:** Negócios e Carreira (ou Empreendedorismo Digital)
- **Idioma:** Português (Brasil)
- **Preço:** `R$ 97,00`
- **Moeda:** BRL
- **Formato de pagamento:** pagamento único
- **Garantia:** 7 dias

### 1.2 Descrição do produto (colar)
Use a seção [HERO] + [DOR] + lista de entregáveis de:
`ventures/01-funcionarios-digitais/vendas/pagina-de-vendas.md`
(o arquivo está marcado por seções [HERO], [DOR], [VIRADA], [ENTREGAVEIS], [FAQ] — cole na ordem)

### 1.3 Upload de arquivos
- Arquivo principal: `funcionarios-digitais.pdf` (gerado no Passo 0)
- Material complementar: `bonus-funcionarios-digitais.zip`

### 1.4 Programa de afiliados (CRÍTICO — é a sua distribuição)
- **Menu:** Ferramentas → Programa de afiliados → Ativar
- **Comissão:** `60%`
- **Tipo de atribuição:** último clique
- **Duração do cookie:** `60 dias` (ou "eterno" se disponível)
- **Aprovação:** automática (mude p/ manual se aparecer afiliado spammer)
- **Disponibilizar na vitrine (Mercado de afiliados):** ✅ SIM — é daqui que vêm os afiliados
- **Materiais para afiliados:** subir o conteúdo de `vendas/kit-afiliado.md` como material de divulgação

### 1.5 E-mails pós-venda
- **Menu:** ListBoss / Automação (ou integração de e-mail)
- Colar a sequência de 5 e-mails de `vendas/emails-pos-venda.md` (D0, D+2, D+5, D+10, D+21)

### 1.6 Enviar para revisão
- Hotmart revisa o produto (1-3 dias úteis). Status fica "Em análise" → "Aprovado".
